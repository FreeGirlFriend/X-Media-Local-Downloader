# X 媒体本地下载器

通过 Tampermonkey 在 X/Twitter 页面发现帖子并按顺序排队，再交给本机 Python 程序下载图片和视频。自动任务不再通过 Chrome 的模拟点击保存文件。

## 使用前

- Windows、Python 3 和 Tampermonkey。
- 在 Tampermonkey 中安装 `x-media-local.user.js`。如果已经安装旧版，直接替换旧脚本内容并保存，或先禁用旧版，避免重复运行。
- 网络需要能够访问 X 的媒体域名；Python 使用的代理或 VPN 设置可能与浏览器不同。

## 设置保存位置

用文本编辑器打开 `downloader.py`，找到顶部：

```python
SAVE_DIRECTORY = r""
```

留空时，下载内容保存在本项目目录下的 `下载文件` 文件夹。也可以填入完整路径，例如：

```python
SAVE_DIRECTORY = r"D:\X媒体"
```

保留引号前的 `r`，保存文件后重新启动下载器。Windows 路径不需要事先创建文件夹。也可以在命令行启动时通过 `--directory "D:\X媒体"` 临时覆盖脚本设置。

## 运行

1. 双击 `启动下载器.bat`，保持窗口打开。或在项目目录执行 `py -3 downloader.py`。
2. 刷新 X 页面，在脚本面板设置命名方式、滚动间隔等，点击“开始”。无需 API Key 或配对口令。
3. 下载器窗口显示每个文件的保存结果或错误。结束后关闭窗口或按 Ctrl+C。

自动任务逐帖顺序处理；每个帖子开始前和解析媒体地址前经过原脚本的全局随机时钟。同一帖子中的多个媒体按页面识别顺序保存。图片请求 `name=orig`；视频选取脚本能够取得的最高码率 MP4，实际结果仍受 X 返回内容影响。

手动点击帖子上的下载按钮仍使用原脚本的浏览器保存方式。自动任务只有在本地服务报告写入完成后才计入完成；同名文件自动增加数字后缀，不覆盖已有文件。单个文件下载失败后会继续处理其他媒体和帖子。点击“列出失败”，脚本会向 Python 窗口打印失败文件名，并通过油猴 GM_download 请求浏览器逐个下载这些文件；浏览器下载使用浏览器设置的保存目录，文件名和完成情况受油猴及浏览器控制。无法解析媒体地址的失败帖子只能列出，无法自动转交浏览器。刷新页面会丢失失败记录。下载超时后原请求仍可能完成，故转交浏览器可能产生副本。

刷新或关闭页面会清除页面内存中的队列；“从当前帖子开始”不是跨刷新断点续传。持续滚动的发现速度过快、网络加载缓慢或页面结构变化可能造成遗漏，建议核对实际结果。

## 安全与限制

服务只监听 `127.0.0.1`，只接收指定格式的请求，仅下载 `pbs.twimg.com` 和 `video.twimg.com` 的 HTTPS 地址，跳转也会检查。没有口令不代表本机是可信边界：**其他本地程序或具有相应权限的浏览器扩展可能调用该服务**，不要同时运行不可信软件，不使用时请关闭下载器。不要把服务绑定到公网。

随机延迟不能保证不触发 X 的限流或风控。遇到 403、429 等情况请停止并检查，不要反复高频重试。下载受账号权限、网站规则和适用法律约束。

### 滚动和下载间隔

页面连续 5 轮无法滚动时停止扫描轮询，已入队任务继续下载。页面加载缓慢也可能被误判，可重新开始。面板可设置 20–2000 毫秒的媒体下载随机间隔，最大值至少比最小值大 40 毫秒，相邻随机值相差至少 20 毫秒；实际间隔可能因下载耗时更长。随机间隔不能保证避免限流或封禁。
